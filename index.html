Что с Bedrock и Microsoft-входом?+

Для Bedrock на Windows используется официальная установка через Microsoft Store; нужны совместимая Windows, аккаунт и доступ к игре. Minecraft не входит в дистрибутив. Вход Microsoft для Java доступен: приложение получило допуск к Minecraft API. При входе проверяется право на Java Edition.

Можно установить сборку из каталога?+

Встроен каталог Modrinth и импорт локальных архивов сборок. Для прямых загрузок из CurseForge требуется API-ключ издателя; часть файлов может быть ограничена автором проекта. Доступность зависит от источника.

Как подключить ИИ?+

В настройках можно подключить ChatGPT или указать ключ совместимого API. Доступные модели, лимиты и оплата зависят от выбранного сервиса. Отправляются вопрос и выбранный контекст; ключи не размещаются на этом сайте.

About this project / for reviewers+

FLLauncher is an independent Windows desktop launcher and modpack manager. It supports Java instance management, mod dependency visualization, a Modrinth catalog and optional AI assistance. This page distributes the compiled application; launcher source code is not public. The application was approved for the Minecraft API allow list on October 23, 2026.
