Конфиденциальность

Обновлено: 23 октября 2026 года
FLLauncher — настольное приложение для Windows. У проекта нет собственного сервера для сбора аккаунтов, переписки, логов или статистики использования лаунчера. Внешние подключения описаны ниже.

Данные на компьютере

Сборки, настройки, список аккаунтов и выбранные скины сохраняются в локальной папке данных лаунчера. Секреты подключений сохраняются с помощью системного шифрования Windows. Эти данные не включаются в опубликованный EXE. Экспорт сборки не включает учётные записи и ключи лаунчера.

Статус Discord

При включённом статусе лаунчер связывается с запущенным настольным Discord через локальный IPC-канал. Передаётся только фиксированная карточка: FLLauncher, фраза «Лучший лаунчер для Майнкрафта», иконка и ссылка на сайт проекта. Пароли, токены Discord, переписка, названия личных сборок, игровые аккаунты и логи для этой функции не нужны и не передаются.

Настольный Discord обрабатывает и показывает активность по своим правилам и настройкам видимости. Статус можно выключить в «Настройки → Подключения → Discord». При закрытии лаунчера карточка снимается. Для настройки статуса не нужно добавлять бота на сервер или давать ему доступ к сообщениям.

Обновления и история

Проверка новых версий лаунчера обращается к публичному GitHub Releases проекта. При проверке обновлений выбранных модов в выбранный каталог отправляются SHA-1 или fingerprint этих файлов; сами JAR не загружаются. История изменений хранит копии изменяемых модов и паков локально. Галерея читает изображения из папок screenshots на компьютере и не отправляет их на сайт.

Вход, загрузки и помощник

Microsoft/Xbox, Minecraft Services, Modrinth, CurseForge, поставщики Java, Microsoft Store, Google Play и другие выбранные источники обрабатывают запросы загрузки и входа по собственным правилам. Вход проходит через страницы соответствующего поставщика; пароль Microsoft не вводится в FLLauncher.

Если подключён ИИ-провайдер, отправленные вопросы обрабатываются выбранным провайдером. Контекст сборок и журналы отправляются в соответствии с настройками доступа помощника и разрешением на отправку логов. API-ключи и токены подключений используются для выбранного сервиса. Их можно удалить, отключив соответствующее подключение.

Сайт и скачивание

Сайт и готовые релизы размещены на GitHub Pages и GitHub Releases. GitHub обрабатывает обычные сетевые запросы к своим сервисам, включая IP-адрес и технические данные запроса, согласно своей политике. На страницу проекта не добавлены сторонние системы аналитики, рекламные пиксели и формы сбора персональных данных.

Управление и связь

Подключения отключаются в настройках лаунчера. Локальные данные можно удалить с компьютера; удаление аккаунта из списка не удаляет учётную запись у внешнего поставщика. По вопросам проекта можно открыть обращение в репозитории FLLauncher. Не публикуйте в обращениях ключи, токены и личные игровые данные.
